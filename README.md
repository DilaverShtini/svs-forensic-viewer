# 🔍 Smart Vehicular Forensics Viewer

This project implements an interactive replay tool developed for the **Smart Vehicular Systems** master's course.

The goal is to provide a forensic interface capable of reading logs generated by the CARLA simulator (https://carla.org/) and reconstructing the causal chain of events that lead to critical decisions by the autonomous vehicle, such as emergency braking, collisions, or near-misses.

## ✨ Main Features

The architecture separates data generation (Backend/CARLA) from visualization (Frontend/Web), ensuring fluidity and analytical precision through 4 synchronized quadrants:

* 🎥 **Synchronized Video Feed:** Native playback of dashcam frames in perfect sync with the logical timeline, equipped with smart-loading to prevent simulator drop frames.
* 🗺️ **Bird's-Eye View (BEV):** 2D rendering for spatial reconstruction of the Ego Vehicle, obstacles, and pedestrians in the scene.
* 📊 **Progressive Telemetry:** Real-time drawing graphs tracking speed, brake pressure, and **steering angle**, synchronized with the playback slider.
* 🔗 **Dynamic Causal Chain:** Textual inspection that shows not just "what" happened, but "why" (e.g., radar thresholds, V2X triggers).
* 🎯 **Forensic Event Filters:** Ability to isolate specific categories of events, such as *Perception*, *System Actions*, *V2X Network Delays*, and *Critical Collisions*.

## 📡 V2X & Network Delay Analysis
The system specifically models and logs V2X (Vehicle-to-Everything) communication via MQTT. The forensic viewer is capable of exposing hidden infrastructural failures, such as network latency, visually proving when an accident is caused by a delayed warning rather than a sensor failure.

## 🛠️ Technology Stack
* **Backend / Simulation:** Python 3, CARLA Simulator API, Paho MQTT
* **Frontend / UI:** HTML5, CSS3, Vanilla JavaScript
* **Visual Libraries:** HTML5 Canvas API, Chart.js
